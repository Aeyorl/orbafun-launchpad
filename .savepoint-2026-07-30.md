## 🚧 What's Left

### Deploy backend on Render
Use blueprint at https://dashboard.render.com/blueprints → select repo → Render reads `render.yaml`:

**Services (all provisioned automatically):**
1. Postgres: `basic-256mb` ($7/mo)
2. Redis: upgrade to `starter` ($7/mo) for mainnet (currently `free` in yaml)
3. API: `starter` ($7/mo) — Docker build from `apps/api/Dockerfile`

**5 secrets to set in Render dashboard → Environment:**
| Secret | Value |
|---|---|
| `CORS_ORIGIN` | `https://orba.fun` |
| `AUTH_SECRET` | Run `openssl rand -hex 32` |
| `DEPLOYER_PRIVATE_KEY` | Your deployer wallet PK (funded with USDC) |
| `ADMIN_WALLETS` | Comma-separated admin wallet addresses |
| `PINATA_JWT` | From Pinata dashboard (optional) |

**After API is live:**
1. Copy API URL (e.g. `https://orbafun-api.onrender.com`)
2. In Vercel dashboard → set `NEXT_PUBLIC_API_URL` to that URL
3. Set `NEXT_PUBLIC_MAINNET_LAUNCHED=true` in Vercel
4. Rebuild frontend

### Mainnet prep
- Switch RPC URLs from testnet to mainnet in `render.yaml`
- Set `AUTH_ALLOW_INSECURE: "false"` (currently `"true"` for testnet)
- Run E2E test: `node scripts/e2e-full-flow.js`
