# Orba testnet growth start — 2026-09-01

This starts the growth phase on testnet without implying mainnet readiness.

## Public positioning

Orba is a public Arc testnet launchpad for creating and trading fixed-supply
tokens with USDC. Graduation creates a fresh AMM pair, burns the LP tokens, and
renounces token ownership. Users should verify each transaction and graduated
token on Arcscan.

Do not advertise referral accrual as cash, USDC, or a withdrawable reward. It is
currently database accounting only. Keep AI-agent pages, navigation, and
platform-funded execution disabled until the feature is deliberately relaunched.

## First testnet cohort

- Recruit 3–5 identifiable community creators; record the real names/handles only after consent.
- Help each creator launch one distinct test token and share its Arcscan link.
- Target 10 human-created testnet tokens before expanding outreach.
- Give participants a short checklist: Arc testnet network, faucet USDC, verified Orba domain, transaction review, and explorer confirmation.

## 48-hour operating checklist

- Assign a named operator for each monitoring shift.
- Watch API readiness, RPC provider health, indexer lag, failed launches/trades, and support reports.
- Pause promotion if contract addresses, quotes, receipts, or indexed state disagree.
- Log every incident with timestamp, transaction hash, wallet, route, and resolution.

## Initial success measures

- 10 human-created testnet tokens.
- At least 30 successful trades across different wallets.
- No unresolved address mismatch or incorrect quote/receipt display.
- Indexer catches up after traffic bursts without manual database repair.
- Every participant can explain that testnet USDC has no real monetary value.

External creator outreach, social-account creation, and public announcements
require the owner's actual account choices and approval; this document does not
invent or contact anyone.
